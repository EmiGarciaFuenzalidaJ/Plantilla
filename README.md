# Plantilla

Reusable starter template for client landing pages.

## What it is

The structure I reach for when a client landing page starts: responsive layout,
sensible typographic defaults and the sections most of these projects end up
needing, so each new one starts from a working base instead of an empty file.

Not a product — a working starting point, kept here so it stays consistent
across projects.
